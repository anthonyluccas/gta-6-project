## 📖 Sobre o projeto

Projeto de estudo desenvolvido ao vivo durante as 4 aulas do evento **Missão Programação do Zero com IA**, do **DevClub**, com Rodolfo Mori.

O objetivo foi praticar **HTML, CSS e JavaScript** e aprender a integrar uma **IA** em uma aplicação web, usando como tema o universo de **GTA 6**.

## ✨ Funcionalidades

- 🎨 **Manipulação do DOM com JavaScript** para alterar cores, textos e imagens da página dinamicamente.
- 🤖 **Integração com IA via API do Puter**: você envia uma imagem da sua galeria e a IA gera essa mesma imagem no estilo do tema GTA 6.

## 🛠️ Tecnologias

| Tecnologia | Uso |
| --- | --- |
| HTML5 | Estrutura da página |
| CSS3 | Estilização e layout |
| JavaScript | Lógica, manipulação do DOM e chamada à IA |
| Puter (API de IA) | Geração das imagens no estilo GTA 6 |

> O projeto não usa frameworks nem bibliotecas externas.

## 🚀 Como rodar localmente

Não precisa instalar nada. Basta clonar o repositório e abrir o arquivo no navegador:

```bash
# 1. Clone o repositório
git clone https://github.com/anthonyluccas/gta-6-project.git

# 2. Entre na pasta do projeto
cd gta-6-project
```

3. Abra o arquivo `index.html` no seu navegador.

> 💡 Como a geração de imagens depende de uma API de IA, é necessário ter conexão com a internet.
